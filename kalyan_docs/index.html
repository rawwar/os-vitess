Vitess from the inside out.

A 32-chapter, hands-on course that takes you from basic SQL to confidently navigating the Vitess source code and shipping your first pull request.

Each chapter is a slide deck with worked examples, diagrams, hands-on labs, and a checkpoint quiz. Hover any underlined term for a definition. Press ? for keyboard shortcuts.

Who this is for: someone who knows what SELECT and JOIN are and wants to learn how a planet-scale database actually works — and how to contribute to one. We assume only basic SQL and willingness to run a few commands. We teach the rest.
